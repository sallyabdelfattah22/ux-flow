    App shell

    The five regions of every screen

    In Figma

    Every screen is a 1440px desktop frame split into a fixed 280px sidebar and a 1160px main column. The main column stacks four regions top to bottom: header 60px, page title 68px (88px with a back link), content, and footer 54px. Content has 24px padding left and right, leaving 1112px for content.

    Ch. 2

    Grid

    8px base grid

    In Figma

    Frames use an 8px square grid. Sizes and positions should land on multiples of 8, with 4 allowed for small adjustments (icon gaps, badge padding). Off-grid values such as 6, 10 or 20 should be rare and named.

    Column grid for the content area

    Proposed · Q9 open

    Figma has no column grid today; content is laid out with auto-layout at full 1112px width. For dashboards and multi-card layouts, use a 12-column grid with a 24px gutter inside the content area (each column ≈ 70.7px at 1440).

    Breakpoints and screen sizes

    Decided · D-001, D-002

    Team Smart supports desktop (1280px and up) and tablet (768–1279px). There is no phone layout. On wide monitors, tables and dashboards stretch to fill the width; paragraphs and forms stay capped.

    ModeWidthSidebarFont sizes mode
    Desktop1280px and upOpen, 280pxDesktop
    Tablet768–1279pxIcon-only; the header menu button opens itTablet
    Wide (1920px+)same as desktopOpen, 280pxDesktop; tables stretch, text capped at 72ch, forms at 640px

    The Mobile font mode stays in Figma but isn't used. Icon-only sidebar width isn't drawn yet; 72px is suggested.

    Space between page sections

    Decided · D-004

    Use 32px (sections spacing) between major blocks, e.g. the details card and the Employees table. Inside one block, such as the title, search bar, table and pagination, use 16px.

    Typography

    Text styles

    In Figma

    One family, Poppins, in four weights. Eleven text styles: four headings, four Body styles (medium, for labels and UI) and three Description styles (regular, for running text). Sizes shrink on tablet through the Font sizes modes (no phone layout, D-001).

    Type outside the system

    Partly open
    D-007
    The header's “By” and the footer switch from Roboto to Poppins
    The footer uses Regular/Description 2 (Poppins 14). The logo artwork stays as it is.
    D-007
    No text below 12px
    The 10px meta text and “(Optional)” labels move to Description 3 (12px), which is easier to read on control-room monitors.
    Style
    The page title and nav items have no text style
    The page title is 20 / 28 semibold, which matches no style. Either update Body 1 or add a Page title style, then apply styles to nav items too.
    Variables
    Leftover material-theme/* and duplicate font variables
    For example Medium/14 medium and Medium/14 Medium both exist. Remove the duplicates so developers see one name per style.
